# DeepSeek Translate for Raycast

A personal fork of the [Raycast Google Translate extension](https://github.com/raycast/extensions/tree/ebc6660dd359d62915350abb679c3b070184662d/extensions/google-translate), using the DeepSeek API instead of Google Translate.

## Setup

1. Create an API key at [DeepSeek Platform](https://platform.deepseek.com/api_keys) (API usage requires DeepSeek credit).
2. Run `npm ci` in this directory, then `npm run dev` to import the extension into Raycast. Alternatively, run `npm run build` to check the build.
3. Open the extension's preferences in Raycast and enter your key under **DeepSeek API Key**. Raycast stores this as a password preference; do not put your key into source code.
4. Configure source and target languages if needed, then use **Translate**, **Translate Form**, **Quick Translate**, or the instant-translation commands.

Requests go to `https://api.deepseek.com/chat/completions` using `deepseek-chat`. Translation content is sent to DeepSeek; avoid translating confidential text unless your organization's policy allows it. An optional HTTP proxy can be set in preferences. Each translation (including reverse/multiple languages) is a separate billable request. Original actions and UI are retained: Google text-to-speech and the optional “Open in Google Translate” browser action remain available, but in-extension translations are sent only to DeepSeek. Pronunciation is generated by DeepSeek when available.
